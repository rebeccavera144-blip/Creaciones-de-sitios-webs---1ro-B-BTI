Hipótesis

Con este proyecto se busca aprender y enseñar el proceso de creación de sitios web, tanto desde cero utilizando lenguajes de programación básicos (HTML, CSS, JavaScript), como mediante el uso de aplicaciones o plataformas que facilitan el diseño y publicación de páginas, así para ver alternativas de creación de sitios webs tanto para personas que ya tienen conocimiento sobre programación y para personas que no se tienen conocimientos programación.

Delimitación de la investigación

Este proyecto se enfocará en conocer las herramientas más accesibles para crear sitios web, limitándose al uso de plataformas visuales como Wix, Google Sites y Webnode, y a una introducción básica a la programación con HTML. No se incluirá el uso de bases de datos, lenguajes de programación avanzados como JavaScript ni la configuración avanzada. El proyecto se centrará únicamente en la diferencia entre el uso de plantillas y la creación básica con código.

Justificación

Decidimos tomar este tema ya que nos interesó mucho la creación de sitios web. Hoy en días las páginas web son fundamentales para casi todo, desde buscar información hasta comprar cosas o promocionar un negocio. Nos pareció importante aprender cómo se crean, como estudiantes del primer año de Bachillerato Técnico en la Informática queremos empezar a conocer herramientas básicas que nos permitan crear sitios web, aunque no sepamos programar de forma avanzada. También queremos entender qué opciones existen y qué ventajas tiene cada una, ya sea usar una plantilla o programar desde cero. Este proyecto nos aparece una buena oportunidad para aprender algo nuevo que puede servirnos tanto ahora como en el futuro.

¿Qué son los Sitios Webs?

Un sitio web es un conjunto de páginas web bajo un mismo nombre de dominio. Una página web es un documento o información en línea que se encuentra alojada en un servidor de Internet. Estas páginas suelen contener texto, imágenes, vídeos u otros contenidos multimedia que los usuarios pueden ver a través de su navegador web.

Tipos de Sitios Webs

Existen muchas variedades de sitios web. A continuación se listan algunas categorías y ejemplos representativos:

  • Sitio archivo: p. ej. Internet Archive.
  • Blog: p. ej. WordPress.
  • Sitio de empresa, e-commerce: p. ej. Amazon.
  • Comunidad virtual: p. ej. Facebook.
  • Sitio de base de datos: p. ej. IMDb.
  • Otros: directorios, descargas, juegos, noticias, streaming (Netflix/YouTube), portales, colaborativos (Wikipedia), educativos, políticos, religiosos, etc.

Historia de los Sitios Webs

La Web se desarrolló entre mayo de 1989 y diciembre de 1990 por Tim Berners-Lee (con la ayuda de Robert Cailliau) en el CERN, y se publicó en 1991. Desde entonces la web ha evolucionado de páginas estáticas a aplicaciones interactivas y servicios inteligentes que integran bases de datos, APIs y en algunos casos inteligencia artificial.

En los primeros años, los sitios eran puramente informativos y muy básicos. Con el tiempo surgieron navegadores más avanzados, se incorporaron imágenes, estilos y más tarde lenguajes como JavaScript. Hoy en día los sitios web son dinámicos, interactivos y fundamentales en la vida diaria.

Cómo hacer un sitio web (una guía resumida)

  1. Planifica: define el objetivo, público, contenidos y estructura de tu web.
  2. Elige la vía: usar una plantilla (Wix/Google Sites/Webnode) o programar con código (HTML, CSS básico).
  3. Diseño: selecciona la plantilla o dibuja un esquema de cómo quieres que se vea.
  4. Desarrollo: si usas código, crea archivos como index.html y styles.css. Si usas plantilla, edita los bloques prediseñados.
  5. Contenido: agrega textos, imágenes, enlaces y metadatos relevantes.
  6. Pruebas: revisa en diferentes navegadores y dispositivos.
  7. Publica: sube tu web a un hosting y compra un dominio o publica directamente desde la plataforma usada.
  8. Mantenimiento: actualiza, mejora y corrige errores regularmente.

Tip: Usa la extensión Live Server en VS Code para ver cambios al instante mientras programas.
